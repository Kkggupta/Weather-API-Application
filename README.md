# Weather-API-Application
Weather API App is a simple web-based application developed using HTML, CSS, and JavaScript. The main purpose of this project is to fetch and display real-time weather details of any city around the world using a public Weather API like OpenWeatherMap. The application allows users to enter the name of a city and get current weather information such as temperature, humidity, and wind speed. It provides an easy-to-use interface with a clean and responsive design that works well on both desktop and mobile devices.

To build this project, basic frontend technologies were used: HTML for structure, CSS for styling, and JavaScript to handle logic and API integration. The weather data is fetched dynamically by making API calls in JavaScript, and the results are displayed directly on the web page. The project also allows users to update the search and see weather changes in real time.

This application can be enhanced further by adding features like a five-day forecast, geolocation support to detect the user's current location automatically, and a dark mode theme.
